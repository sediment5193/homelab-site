## What it does

Proxmox is a type 1 hypervisor that can be used to host multiple virtual machines on bare metal. It's got a web GUI, supports clusters of multiple machines, and has too many cool features to list.

This is the first piece of software I deployed for my homelab and is the foundation that everything else is deployed on top of.
